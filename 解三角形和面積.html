解三角形與面積計算（完整互動簡報）

投影片 1：基礎公式對照表

1. 正弦定理 (The Law of Sines)

\[\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}\]

主要用於 ASA、AAS 以及 SSA（二義性/不確定）情況。

2. 餘弦定理 (The Law of Cosines)

\[a^2 = b^2 + c^2 - 2bc \cos A, \quad \cos A = \frac{b^2 + c^2 - a^2}{2bc}\] \[b^2 = a^2 + c^2 - 2ac \cos B, \quad \cos B = \frac{a^2 + c^2 - b^2}{2ac}\]

主要用於 SSS 和 SAS 情況。

3. 面積公式

標準公式： \(\text{面積} = \frac{1}{2} \times \text{底} \times \text{高}\)

SAS 公式： \(\text{面積} = \frac{1}{2}ab \sin C = \frac{1}{2}bc \sin A = \frac{1}{2}ac \sin B\)

ASA / AAS 公式： \(\text{面積} = \frac{c^2 \sin A \sin B}{2 \sin C}\)

希倫公式 (SSS)： \(\text{面積} = \sqrt{s(s-a)(s-b)(s-c)}\)，其中 \(s = \frac{a+b+c}{2}\)

黃金法則： 標準標記法假設三角形為 \(\triangle ABC\)，其邊長 \(a, b, c\) 分別對應對角 \(\angle A, \angle B, \angle C\)。務必確保計算器的角度模式已設定為角度 (Degrees) 或弧度 (Radians)。

投影片 2：SSS – 銳角三角形

例題 1：已知 \(\triangle ABC\) 中 \(a = 5\), \(b = 6\), \(c = 7\)

步驟 1：使用餘弦定理求 \(\angle A\)

\[\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{6^2 + 7^2 - 5^2}{2(6)(7)} = \frac{60}{84} \implies \angle A \approx 44.42^\circ\]

步驟 2：使用餘弦定理求 \(\angle B\)

\[\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{5^2 + 7^2 - 6^2}{2(5)(7)} = \frac{38}{70} \implies \angle B \approx 57.12^\circ\]

步驟 3：使用內角和定理求 \(\angle C\)

\[\angle C = 180^\circ - 44.42^\circ - 57.12^\circ = 78.46^\circ\]

步驟 4：使用希倫公式求面積

\[s = \frac{5+6+7}{2} = 9 \implies \text{面積} = \sqrt{9(4)(3)(2)} = \sqrt{216} \approx 14.70\]

\[\angle C = 180^\circ - 40^\circ - 48.62^\circ = 91.38^\circ\]

步驟 4：計算面積

\[\text{面積} = \frac{1}{2}bc \sin A = \frac{1}{2}(6)(8)\sin(40^\circ) \approx 15.43\]

投影片 12：SSA – 不確定情況（雙解/兩組解）

例題 11：已知 \(\triangle ABC\) 中 \(\angle A = 30^\circ\), \(a = 7\), \(b = 10\)

步驟 1：檢查垂直高度條件 \(h = b \sin A = 10 \sin(30^\circ) = 5\)

因為 \(h < a < b\)（即 \(5 < 7 < 10\)），故存在恰好兩組合法的三角形解！

解 1（銳角 \(\angle B_1\)）：

\[\sin B_1 = \frac{b \sin A}{a} = \frac{10(0.5)}{7} = 0.7143 \implies \angle B_1 \approx 45.58^\circ\] \[\angle C_1 = 180^\circ - 30^\circ - 45.58^\circ = 104.42^\circ\]

解 2（鈍角 \(\angle B_2\)）：

\[\angle B_2 = 180^\circ - 45.58^\circ = 134.42^\circ\] \[\angle C_2 = 180^\circ - 30^\circ - 134.42^\circ = 15.58^\circ\]

選擇題練習

Q1. 已知 \(\angle A = 30^\circ\), \(b = 12\)。邊長 \(a\) 在什麼範圍內會產生兩組解？
提示： 高度 \(h = 12 \sin(30^\circ) = 6\)。當滿足 \(h < a < b\) 時存在兩解。
黃金法則： 在 SSA 情況下，當 \(b \sin A < a < b\) 時會產生雙解。

投影片 13：SSA – 唯一解情況

例題 12：已知 \(\triangle ABC\) 中 \(\angle A = 30^\circ\), \(a = 12\), \(b = 8\)

步驟 1：比較邊長

由於 \(a \ge b\)（即 \(12 \ge 8\)），邊長 \(a\) 只能朝底邊的一側延伸，故恰好只能組成一個合法三角形（唯一解）。

步驟 2：求解該唯一三角形

\[\sin B = \frac{b \sin A}{a} = \frac{8 \sin(30^\circ)}{12} = \frac{4}{12} = 0.3333 \implies \angle B \approx 19.47^\circ\] \[\angle C = 180^\circ - 30^\circ - 19.47^\circ = 130.53^\circ\] \[c = \frac{a \sin C}{\sin A} = \frac{12 \sin(130.53^\circ)}{\sin(30^\circ)} \approx 18.24\]

選擇題練習

Q1. 若 \(\angle A = 40^\circ\), \(b = 10\) 且 \(a = 15\)，能組成多少個三角形？
提示： 當 \(a \ge b\) 時，永遠只有恰好一個唯一解。
黃金法則： 若 \(a \ge b\)，SSA 的二義性消失，僅產生 1 個解。

投影片 14：SSA – 無解情況

例題 13：已知 \(\triangle ABC\) 中 \(\angle A = 30^\circ\), \(a = 4\), \(b = 10\)

步驟 1：計算垂直高度 \(h\)

\[h = b \sin A = 10 \sin(30^\circ) = 5\]

步驟 2：比較邊長 \(a\) 與高度 \(h\)

因為 \(a < h\)（即 \(4 < 5\)），邊長 \(a\) 長度不足以接觸底線。無法組成任何三角形！

\[\sin B = \frac{10 \sin(30^\circ)}{4} = \frac{5}{4} = 1.25 > 1 \quad (\text{無解/不可能！})\]

選擇題練習

Q1. 已知 \(\angle A = 45^\circ\), \(b = 10\)。下列何者 \(a\) 的值會導致「無解」？
提示： 最低高度需求 \(h = 10 \sin(45^\circ) \approx 7.07\)。任何小於 \(7.07\) 的 \(a\) 值皆無解。
黃金法則： 若 \(a < b \sin A\)，則 \(\sin B > 1\)，代表不存在任何三角形。

投影片 15：實際應用 – 方位角與距離

例題 14：\(\triangle PQR\) 中的航海方位角問題

一艘船由 P 點出發，沿方位角 060° 行駛 10 km 到達 Q 點；隨後轉向沿方位角 150° 行駛 15 km 到達 R 點。

\[\angle Q = (180^\circ - 60^\circ) + 150^\circ = 120^\circ + 150^\circ = 270^\circ \implies \text{三角形內角 } \angle Q = 360^\circ - 270^\circ = 90^\circ\]

步驟 2：計算直線距離 PR

\[PR = \sqrt{10^2 + 15^2} = \sqrt{100 + 225} = \sqrt{325} \approx 18.03\text{ km}\]

Q1. 距離 PR 四捨五入至小數點後 1 位是多少？

投影片 16：組合圖形與四邊形面積

例題 15：求四邊形 ABCD 的面積

利用對角線 AC 將四邊形 ABCD 分割為 \(\triangle ABC\) 及 \(\triangle ADC\)。

步驟 1：求 \(\triangle ABC\) 面積（已知 \(AB=6, BC=8, \angle B=60^\circ\)）

\[\text{面積}_1 = \frac{1}{2}(6)(8)\sin(60^\circ) = 24(0.8660) \approx 20.78\]

步驟 2：使用餘弦定理求對角線長度 AC

\[AC = \sqrt{6^2 + 8^2 - 2(6)(8)\cos(60^\circ)} = \sqrt{100 - 48} = \sqrt{52} \approx 7.21\]

步驟 3：使用希倫公式求 \(\triangle ADC\) 面積（已知 \(AD=9, CD=7, AC=7.21\)）

\[s = \frac{9 + 7 + 7.21}{2} = 11.605 \implies \text{面積}_2 \approx 24.87\]

四邊形總面積： \(20.78 + 24.87 = 45.65\)

選擇題練習

Q1. 對角線 AC 的長度是多少？
提示： 對 \(\triangle ABC\) 套用餘弦定理：\(AC = \sqrt{6^2+8^2-2(6)(8)\cos 60^\circ}\)。

投影片 17：總結與決策樹

解三角形策略速查表

  • SSS： 先用餘弦定理求最大角 \(\to\) 餘弦/正弦定理 \(\to\) 希倫公式求面積。
  • SAS： 用餘弦定理求未知邊 \(\to\) 正弦定理求較小角 \(\to\) 面積 = \(\frac{1}{2}ab \sin C\)。
  • ASA / AAS： 內角和定理 (\(180^\circ - A - B\)) \(\to\) 正弦定理求邊長 \(\to\) ASA 面積公式。
  • SSA： 比較邊長 \(a\) 與垂直高度 \(h = b \sin A\)：
    • \(a < h \implies 0\) 個解（無解）
    • \(a = h\) 或 \(a \ge b \implies 1\) 個唯一解
    • \(h < a < b \implies 2\) 個獨立解（雙解）
